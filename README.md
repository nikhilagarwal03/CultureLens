# 🌍 The Problem

The internet connects billions of people, but **cultural understanding remains fragmented**.

Every day, users encounter memes, slang, and traditions from other cultures that make little sense without context.

Traditional translation tools convert **words**, but they fail to translate the **cultural meaning behind them**.

---

# 🚀 The Solution — CultureLens

**CultureLens acts as a Cultural Rosetta Stone for the internet.**

Instead of translating words, it translates **cultural context**.

It takes a concept from one culture and explains it using **analogies from the user's own culture**, making it instantly relatable.

### Example

**Input**

> What is the Super Bowl?

**Explanation for an Indian user**

> The Super Bowl is comparable to the **IPL Final combined with the scale of a national festival**.
> It is the championship game of American football and one of the biggest sporting and entertainment events in the United States.

This makes global internet culture **understandable for everyone**.

# 🧠 The CultureLens Insight Engine

Most AI tools generate a single block of explanation.

CultureLens instead breaks cultural understanding into **five structured layers**, making complex cultural references easier to understand.

### Reference

A clear explanation of the term or concept.

### Origin Culture

Identifies where the term originated and the community that popularized it.

### Cultural Impact

Explains how the concept spread and why it became influential.

### Local Analogy

Compares the concept with something familiar in the user's cultural context.

### Context

Shows how and where the term is commonly used in real conversations online.

This structured approach transforms CultureLens from a simple AI explanation tool into a **true cultural interpretation engine**.

# 💻 Run Locally

Clone the repository:

```
git clone https://github.com/nikhilagarwal03/CultureLens.git
cd CultureLens/client
```

Install dependencies:

```
npm install
```

Start the development server:

```
npm run dev
```

Open:

```
http://localhost:3000
```

---

# 🔑 Environment Variables

Create a `.env.local` file and add:

```
MONGODB_URI=your_mongodb_connection_string
MONGODB_DB_NAME=culturelens
OPENROUTER_API_KEY=your_openrouter_api_key
OPENROUTER_MODEL=openai/gpt-oss-20b:free
LINGO_API_KEY=your_lingo_api_key
```

Notes:

• Ensure your MongoDB Atlas cluster is running
• Whitelist your IP or use `0.0.0.0/0` for development
